# MailPulse

**Turn your inbox into intelligence.**

MailPulse is an AI-powered Gmail Analytics & Intelligence platform. This repository contains the **Phase 1** implementation: the Source & Access Layer and Application / Orchestration Layer.

## Product Overview
MailPulse connects to a user's Gmail account and creates a structured data foundation for email analytics and future AI-powered email intelligence.

**Currently implemented (Phase 1):**
- Project scaffolding (Docker, FastAPI, Postgres)
- Database Architecture and Alembic migrations
- Basic Backend Structure

**Intentionally NOT implemented (reserved for future phases):**
- BERT Classifier
- Sentence-BERT / FAISS / Qdrant
- ML Predictions (Priority, Action required, Summarization)
- Semantic Search

## Architecture Summary
**1. Source & Access Layer:** Gmail -> Gmail API -> OAuth 2.0 -> Backend
**2. Application / Orchestration Layer:** FastAPI Backend -> Email Ingestion -> Normalization -> Preprocessing -> DB Storage -> API Layer -> Frontend Dashboard

### Recommended Phase 2 Architecture (AI/Intelligence Layer)
```
Preprocessed Email
       ↓
AI Processing Pipeline
       ↓
BERT (Categorization) + Sentence-BERT (Embeddings)
       ↓
Qdrant Vector DB (Semantic Search)
       ↓
Feature Fusion + MLP
       ↓

```

## How to Run Locally

1. Start the PostgreSQL database using Docker Compose:
   ```bash
   docker compose up -d
   ```
   *(This will expose the database on `localhost:5432` with the default credentials).*
2. Navigate to the backend directory and create a virtual environment:
   ```bash
   cd backend
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. Create a `.env` file in the `backend/` directory based on `.env.example`.
4. Run database migrations:
   ```bash
   alembic upgrade head
   ```
5. Start the FastAPI server:
   ```bash
   uvicorn app.main:app --reload
   ```
6. Access the API at `http://localhost:8000/docs`.
7. Access the Frontend (once built) at `http://localhost:5173`.
